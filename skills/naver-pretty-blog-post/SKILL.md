# 리도 양식 네이버 블로그 글 만들기

도구는 이 스킬의 `scripts/`와 `references/`에 들어 있다. 내 PC의 작업 폴더(예: `C:\Users\내이름\NaverProfiles\`)에 `toolkit\` 폴더를 만들고 `scripts/` 안 파일과 `references/WORKFLOW.md`를 복사해 둔 뒤 쓴다. 먼저 `WORKFLOW.md`(발행 절차·규칙)를 읽는다. 코드는 REPL에서 `globalThis.NAVER_ROOT='…\\NaverProfiles\\'; eval(await fs.readFile(NAVER_ROOT+'toolkit\\naver-post-lib.js','utf8'))` 로 불러 쓴다. 사용자 보고는 쉬운 한국어로 짧게.

## 양식 (이 모양을 지킨다)
- 구성: 대표 이미지 1장 → 도입(이모지 + 독자 상황 2~3줄) → 확인 날짜 줄 → `---` → `## 1️⃣ 질문형 소제목` 4개(각 소제목 아래 첫 문장이 답) → 도식 2장(소제목 2 또는 3 아래, 4 아래) → `💡 꿀팁포인트` → 공식 링크 URL → 🌱 마무리 → 해시태그 10개.
- 문단은 한 줄 15~25자로 끊고 문단 사이 한 줄 띄운다. 소제목은 큰 글씨(24px) + 블로그 대표색, 핵심어는 강조색, 가장 중요한 구절은 형광펜(연노랑). 이모지를 문장 곳곳에.
- 말투는 합니다체, 본문 공백 제외 1,200~1,800자. 후기·경험·수치를 지어내지 않고 공식 자료를 직접 읽은 내용만 쓴다. 건강 글은 진단·치료를 대신하지 않는다는 문구, 재테크 글은 투자 권유·수익 보장 금지.
- 이미지: 대표(공개 이미지 또는 AI 사진, 글자·얼굴 없음) + 3D 귀여운 도식 2장(순서도/비교표/요약 카드/체크리스트를 글마다 다르게). 도식은 `genBg`로 만든 글자 없는 3D 배경 위에 `renderCard`로 정확한 한글을 올린다(AI 이미지에 한글을 직접 그리지 않는다).
- 글 검사: `lintPost(txt, title, 건강글이면 true)` 통과 후 발행.
- 글 표기법(txt): 빈 줄 = 문단, `## 소제목`, `---` 구분선, `@img1`/`@img2` 이미지 자리, `**강조**`, `==형광펜==`, 마지막 줄 `#해시태그`.

## 새 네이버 블로그에 적용하는 순서
1. 사용자가 블로그 주소(ID), 주제, 카테고리 3개, 대표색을 정하게 한다. 로그인은 사용자가 직접 한다(비밀번호를 받거나 입력하지 않는다).
2. 전용 크롬 프로필 폴더를 새로 만들고, 서로 다른 디버그 포트로 연다: `chrome.exe --user-data-dir=<폴더> --remote-debugging-port=<포트> --remote-allow-origins=* --no-first-run --new-window https://nid.naver.com/nidlogin.login`. 사용자가 "로그인 상태 유지"를 체크하고 로그인하게 한다. 중계 프로그램은 `scripts/relay.cjs`(포트 9300).
3. `naver-post-lib.js`의 `NPC.blogs`에 블로그를 추가한다(port, dir, acc 대표색, ink 글자색, bg 배경 파일 2개).
4. 배경 2장을 `genBg(블로그ID, '3D 소품 영어 나열', 'bg_이름_a.png', '대표색 영어 팔레트')`로 만든다.
5. 블로그 정보(이름, 별명, 소개글, 주제, 프로필 사진)와 카테고리 3개를 만든다. 카테고리는 관리 > 메뉴·글·동영상 관리 > 블로그 화면에서 `img._addCategoryView`를 실제 마우스로 눌러 추가하고 이름은 `#category_name`에 넣은 뒤 `#submit_button`으로 저장한다.
6. `queue/<ID>.json`(카테고리별 주제 목록), `categories.json`, `ledger/<ID>.json`을 만든다(`examples/` 참고).
7. 첫 글을 직접 발행해 사용자에게 보여주고, 승인 후에 자동 발행 루틴을 만든다: 블로그마다 루틴 1개, 시각은 카테고리 수만큼, 프롬프트는 "`WORKFLOW.md`를 읽고 따른다 + 블로그ID/포트/카테고리 순서"를 담아 자기완결적으로 쓴다.

## 글 하나만 만들 때
`WORKFLOW.md` 3~5절 순서로: 공식 자료 조사 → txt 표기법으로 글 작성 → lint → 대표 이미지(`genHero`) → 도식 2장(`renderCard`) → `buildPost` → `publish(포트, '카테고리')` → 공개 주소 확인 → 보고.

## 주의
- 네이버 블로그 주소는 한 번만 바꿀 수 있다. 바꾸려면 변경 창 확인 후 블로그 정보 화면 하단 확인까지 눌러야 저장된다(`scripts/change-addr.cjs`). 사용자가 승인한 경우에만 한다.
- 로그인 풀림, 캡차, 계정 전환이 필요하면 멈추고 사용자에게 알린다. 사용자가 지정하지 않은 블로그는 건드리지 않는다.
- 편집기 입력은 서식을 붙여넣는 방식(HTML 붙여넣기)이 안정적이다. 굵게 서식은 붙여넣기에서 빠지므로 색과 크기로 강조한다. `<hr>`로 시작하는 붙여넣기는 실패하므로 구분선은 툴바 버튼으로 넣는다.
- 중계/크롬 창이 사용자 조작으로 꺼질 수 있다. 꺼져 있으면 같은 프로필로 다시 연다. 강제 종료 후 다시 열면 로그아웃될 수 있다.

## 다른 사이트(워드프레스 등)로 옮기기
같은 txt 글과 도식 이미지를 쓰고 발행 방식만 바꾼다. 워드프레스는 사용자가 만든 애플리케이션 비밀번호로 REST API(`/wp-json/wp/v2/posts`, 미디어 업로드)를 쓰거나 관리자 편집기에 HTML 블록으로 붙여넣는다. 이모지·형광펜(`<mark>`)·소제목·구분선(`<hr>`)은 HTML로 그대로 가능하다. 제목·메타 설명·대표 이미지·카테고리를 함께 채우고, 이미지는 대체 텍스트를 넣는다. 승인 없이 비밀번호를 받거나 가입·결제는 하지 않는다.
